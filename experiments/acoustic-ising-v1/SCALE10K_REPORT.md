# 大規模拡張実証レポート：`N = 2,000 / 3,000 / 5,000 / 10,000` スピン検証

更新日: 2026-11-03 JST

## 1. 結論：`N = 2,000〜10,000` の成立性と物理音響限界の客観評価

1. **PC内純粋位相計算（Phase 1 `PhaseODEBackend`）：全規模（`N = 2,000, 3,000, 5,000, 10,000`）で完全成立**
   - 既存の `IsingProblem` / `AnnealingSchedule` / `IsingAnnealer` を1行も変更せずそのまま実行し、疎グラフ **Max-Cut 10,000（30,000辺）** は単独プロセス Peak RSS **`263.3 MiB`**・ソルバー時間 **`15.855` 秒**（32軌道バッチ、1スレッドBLAS）で完走した。
   - 最悪ケースである **全結合 Gaussian SK 10,000（49,995,000結合 $\approx$ 約5,000万結合）** も、倍精度 `float64` 密行列（`763.0 MiB`）のまま単独プロセス Peak RSS **`1573.1 MiB`**・ソルバー時間 **`102.81` 秒**（16軌道バッチ、1スレッドBLAS）で完走した。
   - **Max-Cut 全規模（`2,000, 3,000, 5,000, 10,000`）および `SK 2,000 / 3,000`（計6条件）で古典 Greedy を上回る最良解**：同一初期数（32初期値）の最急1スピン反転 Greedy に対し、`maxcut10000` ではエネルギー `-43591.0` 対 `-40199.0`（カット値 **`+1,696` 上積み**）を達成した。一方、超大規模密結合の `SK 5,000 / 10,000` では固定 `800` ステップのままパラメータ無調整で回したため Greedy 最良値との差が約 `0.6%`（`sk10000` で `-7028.9` 対 `-7071.4`）となった（平均エネルギーやステップ数延長余地も含め無選別でそのまま報告する）。
2. **48 kHz 仮想音波ループバック（Phase 2 `AudioLoopbackBackend`）：`N = 10,000` 同時多重まで数値的・信号処理的に完全成立**
   - 48 kHz サンプリングの倍音干渉フリー帯域 `[10 kHz, 20 kHz)` において、フレーム長 $M = 19,200 \sim 96,000$ サンプル（周波数分解能 $\Delta f = 2.50 \sim 0.50\,\text{Hz}$、全条件で最小2ビン間隔）をとることで、**10,000本の独立サイン波を窓漏れゼロ・第2高調波被りゼロで `irfft`/`rfft` 一括変復調**でき、仮想室内多重反射＋42 dB AWGN 下でも `N = 2,000〜10,000` 全条件で正常に低エネルギー解へ収束することを確認した。
3. **実音スピーカー＆マイク（Phase 3 `RealAcousticBackend`）における物理的トレードオフ（重要）**
   - PC内（Phase 1）およびデジタル波形ループバック（Phase 2）では `N = 10,000` まで問題なく動作するが、**実空間のスピーカー＆マイク再生（Phase 3）**では、`10 kHz` 帯域幅に `10,000` 音（2ビン間隔で $\Delta f = 0.5\,\text{Hz}$）を詰め込むと 1フレームの録音長が $T = 2.0\,\text{秒}$ 必要となり、800ステップの実時間再生に約 `26.7分/軌道` を要するほか、室温空気対流によるドップラー揺らぎや1音あたり振幅 $1/\sqrt{10000}$（$-40\,\text{dB}$）のマイク量子化・背景騒音限界が効いてくる。
   - したがって、**48 kHz 実スピーカー＆マイク運用の実用スイートスポットは `N <= 500〜2,000` 程度**（または 96 kHz / 192 kHz 超音波オーディオインターフェース併用）、**`N = 3,000〜10,000+` の大規模最適化は `PhaseODEBackend`（PC内高速計算）で回すハイブリッド運用**が物理的・工学的に最適である。
